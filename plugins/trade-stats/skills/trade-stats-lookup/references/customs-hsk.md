# 관세청 정밀 조회 (`domestic`) — HSK 10단위

이 스킬에서 **유일하게 인증키가 필요한 기능**이다. 기본 동작이 아니므로 사용자가
명시적으로 요구할 때만 읽고 실행한다.

**이 스킬은 키 없이 쓰는 도구다.** `market` · `discover` · `products` · `hs-search` · 관세율은
전부 키 없이 돈다. `domestic` 하나만 관세청 인증키가 필요하고, **먼저 권하지 마라.**

### 언제만 쓰나

사용자가 **명시적으로 이 중 하나를 물었을 때만** 꺼낸다:

- HS 6단위로는 우리 제품이 특정이 안 될 때 — "우리는 그 코드 안에서도 OO만 만든다",
  "8507에 납축전지랑 리튬이온이 같이 잡히는데"
- **단가가 오른 이유**를 물을 때 — HS6로는 "가격 변동인지 믹스 변동인지 분해 불가"가
  정답이지만, HSK 10단위면 믹스가 사실상 고정이라 가격 변화로 읽을 수 있다
- **더 최신 숫자**를 요구할 때 — "올해 것 없어?", "작년 데이터로 답하지 마라".
  Comtrade 연간은 1~2년 지연이고 관세청은 익월 공표다
- HSK / 10단위 / 관세청 / HSK코드를 사용자가 직접 언급할 때

반대로 **시장 규모·경쟁국 점유율·매력도·어느 나라부터**는 이걸로 못 답한다. 그건
상대국 신고 통계라서 관세청에 아예 없다. 그런 질문에 `domestic`을 꺼내지 마라.

### 키가 없으면

명령이 발급 안내를 그대로 뱉는다. **그 안내문을 사용자에게 그대로 전달하고, 사과하지 마라.**
그리고 반드시 두 가지를 같이 말한다:

1. **지금 당장 키 없이 답할 수 있는 부분**을 먼저 답한다. HS 6단위 조회, 시장 순위,
   경쟁 구도는 이미 다 된다. 키를 못 받으면 아무것도 못 한다는 인상을 주지 마라.
2. 키로 얻는 것을 한 줄로: "우리 제품 라인만 정확히 + 단가 해석 가능 + 1년 이상 최신".
   무료이고 5분이라는 것도 같이 말한다.

사용자가 "그건 됐고"라고 하면 다시 권하지 마라. HS 6단위 결과로 계속 진행한다.

### 쓰는 법

```bash
python3 analyze.py domestic --hs 330499 --countries 미국,일본,베트남
```

- `--hs`는 2/4/6/10 단위를 받고 **무엇을 넣든 HSK 10단위로 내려가서** 답한다.
  API가 요청보다 한 단계 아래로만 분해하기 때문에 스크립트가 알아서 되짚어 내려간다.
  4단위면 하위 6단위 수만큼 콜이 늘고, 2단위·생략이면 그 나라 전 품목을 한 번에 받는다.
- `--months`는 기본 24다. YoY를 내려면 24가 최소다.
- 국가는 **ISO2가 있는 나라만** 된다(관세청 API 제약). 대만은 안 된다.

### 보고할 때 반드시

- **점유율을 만들지 마라.** 이 수치는 한국 신고 수출(FOB)이고, 시장 규모는 상대국 신고
  수입(CIF) + HS 6단위다. HSK10 금액을 HS6 시장 규모로 나누면 분자만 좁아져 점유율이
  실제보다 낮게 나온다. 숫자는 그럴듯해 보이는데 틀린다. 점유율은 `market` 결과만 쓴다.
- **두 소스의 기준 시점이 다르다는 것을 명시하라.** 관세청은 2026년 7월까지, Comtrade
  시장 통계는 2025년까지 — 한 표에 섞어 놓으면 사용자가 같은 시점으로 읽는다.
- `price_note`가 "단가 변화로 읽어도 된다"고 할 때만 가격 해석을 붙인다. `기타`·`그 밖의`
  로 끝나는 코드는 10단위여도 잡탕이라 스크립트가 그렇게 표시해준다 — 그대로 전달하라.
- 응답에 한글 품목명(`item_name_ko`)이 들어 있다. HSK 코드를 그대로 노출하지 말고
  품목명을 앞세워라 — "3304991000" 보다 "기초화장용 제품류"가 실무 언어다.

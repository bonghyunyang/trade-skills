# 국가 코드

`references/areas.json`에 UN Comtrade 지역 312개(보고국 255개)가 들어 있다.
`references/country_aliases_ko.json`이 한국어 국가명 138개를 코드로 매핑한다.

```bash
python3 scripts/fetch_comtrade.py country-search 카자흐
python3 scripts/fetch_comtrade.py country-search vietnam
```

입력은 ISO2(`KZ`), ISO3(`KAZ`), 숫자코드(`398`), 영문명(`Kazakhstan`), 한글명(`카자흐스탄`)을 모두 받는다.

## 반드시 아는 함정

- **대만은 `Other Asia, nes`(코드 490)** 로 잡힌다. Comtrade가 정치적 중립 표기를 쓴다.
  리포트에는 "대만 (Other Asia, nes)"으로 표시된다. 사용자가 대만을 물으면 이 코드를 쓴다.
- **홍콩(344)과 중국(156)은 별개**다. 중국 시장을 볼 때 홍콩 경유분이 빠진다는 점을 감안하라.
- **World = 코드 0**. 전 세계 합계를 뽑을 때 쓴다. 국가 랭킹에서는 스크립트가 자동으로 제외한다.
- **한국 = 410** (`Rep. of Korea`). 북한은 408(`Dem. People's Rep. of Korea`)이며 사실상 데이터가 없다.
- **EU는 하나의 상대국이 아니다.** 회원국을 각각 조회해야 한다.
- `nes` = not elsewhere specified. 잔여 분류이며 실제 국가가 아닌 항목들이 섞여 있다.

## 보고국 vs 상대국

- **보고국(reporter)**: 자기 무역통계를 UN에 보고하는 나라. 미러 데이터(경쟁국 점유율)를 뽑으려면
  대상국이 보고국이어야 한다. `areas.json`의 `reporter: true`.
- **상대국(partner)**: 다른 나라 통계에 등장하는 나라. 보고하지 않아도 등장한다.

대상국이 보고국이 아니면 스크립트가 "미러 데이터 없음"으로 처리하고 매력도 점수를 남은 축으로만 계산한다.
이때 리포트에 `*` 표시가 붙는다.
